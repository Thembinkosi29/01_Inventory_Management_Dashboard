# Inventory Management Dashboard

## Project Overview

Developed an inventory management dashboard using Microsoft Excel to analyse stock levels, inventory value, sales activity, product categories, and delivery performance.

The project uses a 50-product inventory dataset and demonstrates how Excel can be used to clean, analyse, and visualise business data to support inventory and supply-chain decisions.

## Objectives

- Analyse inventory levels across products and categories
- Calculate total inventory value
- Analyse units sold
- Identify products requiring reorder
- Evaluate delivery performance
- Create KPIs and visual dashboards

## Tools Used

- Microsoft Excel
- Excel formulas
- Data Cleaning
- Data Analysis
- Data Visualization
- KPI Reporting

## Key Results

- **50 products** analysed
- **4,077 total stock units**
- **R1,594,615 total inventory value**
- **2,815 units sold**
- **81.54 average stock per product**
- **37 on-time deliveries**
- **13 late deliveries**
- **0 products requiring reorder**
